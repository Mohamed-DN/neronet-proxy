# ADR NNNN: Title in the imperative or as a noun phrase

- Status: Proposed | Accepted | Superseded by ADR NNNN
- Date: YYYY-MM-DD

## Context

The situation that forces a decision: what the code does today, what constraint or
requirement applies, and which options were considered. State facts that can be
checked. Do not describe how to exploit a weakness; say what is not implemented.

## Decision

What was decided, in one or two declarative paragraphs. If an option was rejected, say
which and why in one sentence each.

## Consequences

What changes in the code, the operation and the documentation because of the decision,
including the costs and the work that follows. List what is not done yet.

## Notes

Optional. Links to the commits, the tests and the other ADRs that this one relates to.
A superseded ADR is kept: change its status and point to the ADR that replaces it.
