NeroNet

An overlay mesh VPN with a web management console, for banks and public administration. Go nodes and a Node.js control plane backed by PostgreSQL and Valkey. Licensed under AGPL-3.0.

Run it locally Read the documentation

What the code does today

Checked against the code on the main branch

Control plane: runs

Nodes enrol, receive an overlay address from 100.64.0.0/10, send a heartbeat every 15 seconds and receive ACL and subnet-route updates. The console shows the values nodes report, and shows a value a node did not measure as unknown.

Node proxy: runs

A node runs a local SOCKS5 and HTTP CONNECT proxy. It refuses private address ranges and a list of abuse ports, then dials the destination directly.

Path selection: runs

The control plane ranks exit bridges by country and selects a three-hop path, with a report of how independent the hops are. No node builds a circuit from it yet.

Data plane: spike

There is no tunnel between nodes in the default configuration. A WireGuard data plane exists behind a node flag, off by default, and reads its peers from a file.

Implemented, not used by a node

Onion cell sealing, NAT traversal, the relay client and the internal Noise transport are implemented and tested. No running node uses them.

Not implemented

Per-node credentials, single sign-on, cryptographic erasure, tamper-evident audit, a post-quantum handshake, release signing, and client applications for any platform.

Run it locally

Needs Podman or Docker. On Windows, use Git Bash.

git clone https://github.com/Mohamed-DN/neronet-proxy.git cd neronet-proxy sh scripts/dev/gen-env.sh sh scripts/dev/stack.sh up sh scripts/dev/stack.sh nodes

The console is on http://127.0.0.1:8443. There is no installer and there are no release downloads.
