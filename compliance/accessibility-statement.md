# Dichiarazione di Accessibilità - NeroNet v4 Console

**Versione**: 4.0.0-rc1  
**Data aggiornamento**: 2026-09-25  
**Responsabile**: Mohamed Abou El Seod

## Conformità

La Console NeroNet v4 è **parzialmente conforme** allo standard WCAG 2.1 Level AA.

I test di conformità sono stati eseguiti con:
- **axe-core** v4.x (integrato nella suite E2E Playwright - WP-411)
- **Screen reader**: NVDA + Firefox
- **Contrasto colori**: APCA e WCAG contrast checker

| Criterio  | Descrizione                        | Stato     |
